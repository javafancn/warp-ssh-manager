# v0.3.2 界面与打包验收规范

本次选用的是用户确认的**上一版深色/浅色对照设计图**；不采用随后生成的新稿。

## 视觉与交互

- 保持 macOS 原生窗口控制区，不再用 GPUI 伪造红黄绿窗口按钮。
- 左侧约 240px 文件夹导航；中间约 382px 连接列表；右侧弹性宽度配置检查器。
- 列表为紧凑双行：主机名称、IP、矢量终端图标与收藏星标；选中使用蓝色底色和精细边框。
- 深色主题使用石墨蓝三层背景；浅色主题使用冷白和浅蓝灰；跟随系统时动态同步。
- 保留单击选中、双击在 Warp 打开、收藏独立点击和快速连接的键盘交互。
- 页面、对话与状态文案使用简体中文；SSH、IP、OpenSSH、Warp 等专有技术名称不翻译。
- 保存成功、校验出错等信息在右侧醒目显示，并支持关闭，不把错误藏在底栏。

## 安装交付

- **Apple Silicon**：`WarpSSHManager-0.3.2-apple-silicon.dmg`
- **Intel**：`WarpSSHManager-0.3.2-intel.dmg`
- 每份 DMG 包含对应架构的 `.app` 和 `Applications` 目录快捷方式，可拖拽安装。
- 应用元数据声明最低 macOS 12；CI 检查 Mach-O 部署版本和架构。
- 当前仅是 Ad-hoc 测试签名，未取得 Developer ID 签名或 Apple 公证；旧系统兼容仍需要 macOS 12 真机验证。
