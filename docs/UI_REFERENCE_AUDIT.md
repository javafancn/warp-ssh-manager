## 视觉令牌（按约1200 × 780 的逻辑窗口尺寸）

- **三栏：** 266 / 446 / flex（剩余约488px），默认高度780，最小尺寸1040×660。
- **顶部：** 66px；操作条与 macOS 原生标题区域连续。
- **主机卡片：** 中栏内容宽约420，图标46px，独立小阴影，名称/IP/标签三层。
- **浅色选中态：** `#DFEDFF → #F3F8FF`，蓝色细描边，深色文字。禁止回退到上一轮的深蓝整块背景。
- **侧栏：** `#E5EBF5 → #EDE4EF`，禁止过亮或饱和紫色。
- **表单：** 行节奏约40px，输入框浅冷白，少用重边框；标签 Chips 必须与主机卡片同色。
- **主题：** 自动、深色、浅色共用布局，使用各自语义色，不以 UI 颜色指示 SSH 在线。
- **数据：** `api` 蓝、`production` 绿、`dev` 紫、`test` 橙、`database` 红。主机和分组绝不使用演示假数据。

## 后续验收

1. 在全新 Mac（0 台主机）打开：显示欢迎页、导入和新增入口，不显示假主机或自动进入编辑表单。
2. 新增/导入后：主机卡片高度、间距、边框及文字层级与参考图对照；单击选择、双击连接、收藏独立点击正常。
3. 编辑标签 `api, production`：右侧出现蓝/绿 Chips，选中卡片实时同步，保存后重启依旧可见。
4. 深色与自动模式：信息密度不变化，文本和控件可读性保持。
5. Intel/Apple Silicon 分开打 DMG，CI 检查成功；macOS 12 真机运行和像素级相似度需实机截图人工验收，不以编译成功代替。
